# NanoCode for Swift

[en](https://nikgariel.github.io/nanocode/en/docs.html) · [ru](https://nikgariel.github.io/nanocode/ru/docs.html) · [zh-CN](https://nikgariel.github.io/nanocode/zh-CN/docs.html) · [es](https://nikgariel.github.io/nanocode/es/docs.html) · [fr](https://nikgariel.github.io/nanocode/fr/docs.html) · [de](https://nikgariel.github.io/nanocode/de/docs.html) · [pt-BR](https://nikgariel.github.io/nanocode/pt-BR/docs.html) · [ja](https://nikgariel.github.io/nanocode/ja/docs.html) · [ko](https://nikgariel.github.io/nanocode/ko/docs.html)

Build from source: `sh scripts/build-apple.sh`; add `packages/apple` as a local Swift package. Release: extract `nanocode-apple.zip`, then add that folder in Xcode. iOS/iPadOS 13+, macOS 11+, device and simulator slices. Native camera capture uses AVFoundation and is not bundled.

Experimental version 0.2.3. See the localized guide for API examples, formats, palettes, permissions and security. Registry publication and real-device testing are separate from source availability. MIT.
