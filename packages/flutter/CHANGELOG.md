## 0.2.1
Faster shared Rust reader with bilinear sampling and local illumination correction. Encoded format and Dart API unchanged. Camera scheduling remains the host application’s responsibility.

## 0.2.0
Initial experimental native FFI adapter. S/M/L/XL generation, scanning, palettes and background suggestions. Release packages bundle native libraries; the source checkout needs `scripts/package-flutter.py`. Flutter Web uses the separate JavaScript package. Not published on pub.dev.
