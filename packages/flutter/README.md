# NanoCode for Flutter (native)

[en](https://nikgariel.github.io/nanocode/en/docs.html) · [ru](https://nikgariel.github.io/nanocode/ru/docs.html) · [zh-CN](https://nikgariel.github.io/nanocode/zh-CN/docs.html) · [es](https://nikgariel.github.io/nanocode/es/docs.html) · [fr](https://nikgariel.github.io/nanocode/fr/docs.html) · [de](https://nikgariel.github.io/nanocode/de/docs.html) · [pt-BR](https://nikgariel.github.io/nanocode/pt-BR/docs.html) · [ja](https://nikgariel.github.io/nanocode/ja/docs.html) · [ko](https://nikgariel.github.io/nanocode/ko/docs.html)

Extract `nanocode-flutter-x86_64.tar.gz` and use a path dependency pointing to its `flutter` directory. The release archive includes Android, iOS, macOS and x86_64 Linux/Windows libraries. Source checkout alone lacks binaries; assemble with `scripts/package-flutter.py` after native builds. Flutter Web uses JS/WASM instead of dart:ffi. This package is not published on pub.dev.

Experimental version 0.2.2. See the localized guide for API examples, formats, palettes, permissions and security. Registry publication and real-device testing are separate from source availability. MIT.
